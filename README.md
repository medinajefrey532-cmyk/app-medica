# MediCitas - Panel Administrativo Médico

Sistema de gestión de citas médicas desarrollado en PHP para la práctica: **"Utilización de Servidor Remoto e Implementación de Plantilla"**.

## 📋 Características del Proyecto
- **Dashboard Principal (`index.php`):** Tarjetas KPI (pacientes atendidos, citas programadas, doctores activos) y tabla de citas médicas del día.
- **Directorio de Pacientes (`pacientes.php`):** Registro y expedientes clínicos.
- **Cuerpo Médico (`doctores.php`):** Lista de especialistas, consultorios y horarios.
- **Agendar Citas (`citas.php`):** Formulario para programar nuevas consultas médicas.
- **Historial Clínico (`historial.php`):** Expediente médico detallado de pacientes.
- **Diseño Responsivo:** Basado en Bootstrap 5 y FontAwesome, adaptado de la plantilla SB Admin 2.
